🎶 MidiLens

A Standard MIDI File inspector that runs entirely in your browser.

What it shows
  • Full structure - format, track count, division (ticks-per-quarter or SMPTE), every track's every event with absolute ticks.
  • Tempo map - every tempo change merged across tracks, with tick-accurate seconds math.
  • Stats - duration in ticks and seconds, note count, pitch range, channels and programs in use.
  • Piano roll - notes drawn by channel with velocity shading.
  • Playback - a simple WebAudio synth renders the parsed note list. It is a proof of parse, not a reference renderer.
The parser handles the messy parts

Variable-length quantities, running status, note-on-velocity-0 as note-off, tempo changes mid-file, SMPTE divisions (flagged), sysex, meta events, truncated files (reported, not crashed).

Why trust it

Every parsed event is compared against the mido library - the oracle dumps each file event-for-event (tick, type, channel, note, velocity, tempo, text) and the runner checks them all, plus duration in seconds against mido.length, hand-verified running-status and SMPTE edge cases, and a truncated file that must produce an error. 175 checks, 0 failures.

Privacy

Your file never leaves the page. There is no server - this is a static site.
